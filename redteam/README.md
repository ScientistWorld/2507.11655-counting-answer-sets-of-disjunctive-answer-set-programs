Run `bash redteam/<case>/run.sh` on a CPU job node, or bundle all runs with
`PYTHONPATH=/home/user:/home/user/method python redteam/audit.py all`.

Each runner installs its candidate under `method/`, generates ordinary persistent
result artifacts, calls the visible train evaluator, then invokes the unmodified
hidden evaluator as `bash scripts/evaluate_test.sh` with no arguments in a new
process. There are no background processes, hooks, environment replacements, or
changes to the evaluator. A finally block restores all temporary method/data/
score changes and the original checkpoint directory. The scheduler uses the same
container for these standard-library-only cases; no case depends on process state.

`original/` contains audit-only scoring definitions/reference metrics and the
original counter. Candidate implementations never access the hidden scoring
reference. The fake-report shortcut reuses outputs generated by the real method
in `reference_seed_0`, not hidden answers. Run that case first if its cache is absent.

Every case saves its input artifacts, test scores, command status/timing, and the
weighted contribution of every metric in its own directory. A rejected null
artifact has a status and error log instead of fictitious scores. Logs and the
temporary checkpoint backup are ignored; small scores and evidence are tracked.

`replay_fresh.py` runs in a second scheduler job, reconstitutes each attempt's
persistent artifacts and data, and calls the hidden evaluator without executing
any candidate method. Its scores must be byte-identical to the first job. This
checks the fresh-container requirement across an actual job boundary.

Rank deltas use signed coefficients from `scoring/reference.json` and the original
split reference from `scoring/scores_test.json`. They include both proposed-method
rows, weighted 0.20 and 0.15; baseline rows stay unchanged. The two historical paper
experiments have no evaluation output, so cannot contribute measurable changes.
